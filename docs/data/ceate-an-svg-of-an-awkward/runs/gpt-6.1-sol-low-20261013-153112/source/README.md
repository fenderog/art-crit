# Misaligned

A text-free, illustrated robot family portrait, drawn entirely in `portrait.svg`: an anxious father, an affectionate mother, a withdrawn teenager, an exuberant little sibling, and a skeptical grandparent.

## Run
Open `project.godot` in Godot 4.7.2 and press F6/F5, or run `godot --path .`.

Move the pointer for a subtle living-photo tilt. Click anywhere or press Space/Enter to capture a photograph with a synthesized shutter and flash. Click again to resume posing; R/Escape also resets the pose. The bottom-right camera/rewind icon indicates the current action. Small dots record up to eight photos.

Self-contained, no plugins or external assets. Uses GL Compatibility; web thread support is disabled. The SVG can also be opened independently.
