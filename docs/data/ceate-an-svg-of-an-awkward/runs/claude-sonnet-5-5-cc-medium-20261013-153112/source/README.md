# Awkward Robot Family Portrait

An SVG family portrait (`portrait.svg`) of six robots with clashing personalities, shown in a Godot 4.7.2 project (gl_compatibility, web-export friendly, no threads).

Cast: stiff grinning Dad with a too-high arm, side-eyeing Mom, a teen turned away, a hyperactive kid, a dozing rusty Grandpa, and a vacuum-dog staring into the lens.

## Run
- Open the folder in Godot 4.7.2 and press F5, or run `godot --path .`
- Main scene: `scenes/main.tscn`
