# Awkward Robot Family Portrait

A hand-written SVG (`portrait.svg`) of a robot family on a sofa: stiff dad, side-eyeing mom, snoozing rusty grandpa, sulking teen, wandering-eyed baby, and a dog staring into the lens. Shown by a Godot 4 scene.

Run: open this folder in Godot 4.x and press F5, or `godot --path .`.
Renderer: gl_compatibility; no threads, web-export friendly.
