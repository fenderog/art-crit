# The Surfing Pelican

A non-interactive, animated Three.js scene: a procedurally built pelican
(white body, black wingtips, S-curved neck, long orange beak and pouch)
stands in a surfing stance on a yellow board, carving endlessly back and
forth across the face of a curling wave. It leans into its turns, balances
with outstretched wings, bobs its head, and kicks up spray, while foam
sheds off the wave's lip, gulls circle, and clouds drift. The camera sways
slowly and tracks the bird on its own — there are no controls to use.

## Run

```sh
npm install
npx serve .   # or any static server; then open the printed URL
```

Everything is generated in code (no downloaded assets), so the packaged
page runs fully offline.
