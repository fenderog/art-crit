# Offshore

A non-interactive coastal daydream: Percy the pelican balances on a striped longboard beside a sculpted turquoise wave. Includes animated wings, gentle bobbing, sea foam and spray, framed by an editorial-style responsive layout.

Built with Three.js and procedural geometry; no external assets, network requests or storage. `index.html` loads the JavaScript ES module and stylesheet.

Install dependencies with `npm install`. Use an ES-module development server with npm package resolution (such as Vite) to preview. The supplied entry is ready for the host's esbuild packaging process.
