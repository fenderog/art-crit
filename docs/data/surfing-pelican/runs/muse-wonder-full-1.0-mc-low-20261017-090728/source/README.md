# Surfing Pelican

An animated, non-interactive Three.js scene: a pelican wearing sunglasses carves back and forth along a curling wave on an orange surfboard, balancing with its wings, wobbling its pouch, kicking up spray, and occasionally hopping off the lip. Gulls, drifting clouds, and a gently swaying cinematic camera complete the loop — no input needed, just watch.

## Run

```sh
npm install
npx serve .        # or any static server, then open index.html
```

Everything (pelican, board, wave, sky) is generated in code from Three.js primitives — no external assets.
