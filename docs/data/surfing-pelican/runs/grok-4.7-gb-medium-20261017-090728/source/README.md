# Surfing Pelican

A non-interactive Three.js scene: a brown pelican carves along a wave at golden hour. The camera follows in front of the beak. Nothing is clickable; the ride loops on its own.

Open it through a static server so the ES modules load:

```
npm install
npx serve .
```

Then visit the URL it prints. `index.html` is the entry, and `main.js` pulls in the rest.
