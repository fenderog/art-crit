# Surfing Pelican

An animated, non-interactive 3D scene built with HTML and Three.js. A white pelican with an orange beak and pouch stands on a red surfboard, riding an animated ocean swell beneath a curling wave, drifting clouds and spray particles. The camera slowly orbits; no controls or interaction are needed.

Run locally: `npx serve .` or any static server, then open `index.html`.
