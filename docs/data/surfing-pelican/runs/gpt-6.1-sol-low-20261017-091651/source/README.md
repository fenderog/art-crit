# Just Coasting

An animated, non-interactive Three.js vignette: a pelican balancing on a coral surfboard, with a sculpted turquoise swell and gently moving foam. Editorial typography frames the scene.

All geometry and materials are generated in JavaScript; no external assets or network requests are needed. Uses the local `three` npm package. Serve `index.html` with an ES-module-aware development server (such as Vite). The page is ready for the provided esbuild packaging workflow.
