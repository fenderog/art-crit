# Surfing Pelican 🦩🌊

An animated, non-interactive 3D scene of a pelican surfing a wave, built with
[three.js](https://threejs.org/) and ES modules.

## Scene
- Procedural ocean with animated layered sine-wave displacement
- A curling wave lip and pulsing foam ring at the break
- A low-poly pelican (body, pouch, flapping wings, webbed feet) carving left
  and right on a surfboard
- Spray particles rising from the board
- Slow cinematic camera drift and soft shadows

## Run
Open `index.html` (bundled version is fully self-contained and works offline).
