# Surfing Pelican

A non-interactive, animated Three.js scene: a pelican built from geometry primitives rides a surfboard on an endless wave, carving side to side with wings spread for balance, spray off the tail, and a curling barrel behind it.

## Run

```sh
npm install
npx serve .   # or any static server, then open index.html
```

No controls — just watch. The camera drifts slowly on its own.

## Files

- `index.html` — entry point
- `main.js` — scene, pelican rig, ocean/wave animation, spray, gulls
